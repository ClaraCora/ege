# po0 防火墙 · Surge

此目录是可独立上传到 `ClaraCora/ege` 仓库的 Surge 版本。上游为 [w0ven/po0fw](https://github.com/w0ven/po0fw)，原作者 `reallinzc`；本副本于 2026-11-12 获取，增加了原生 Panel 排版、请求协调和错误恢复处理。

## 文件与安装

- `po0-firewall-whitelist.sgmodule`：Surge 模块，包含直连规则、定时任务、切网事件和 Panel。
- `po0-firewall-whitelist.js`：模块唯一引用的脚本，已一并保存于此目录。

将整个 `surge/` 目录上传至仓库的 `main` 分支，然后在 Surge 的模块管理中通过以下地址安装：

```text
https://raw.githubusercontent.com/ClaraCora/ege/main/surge/po0-firewall-whitelist.sgmodule
```

安装时在 `tokens` 参数填写自己的 Token。多台机器使用英文逗号分隔，例如 `pgnfw_xxx,pgnfw_yyy`；需要固定槽位时使用 `pgnfw_xxx@0`，槽位从 `0` 开始有效。Token 在 Surge 内填写，仓库中的参数默认留空。

模块三处 `script-path` 均指向本仓库的 `main/surge/po0-firewall-whitelist.js`，运行时不再下载上游脚本，也没有远程图片、字体或脚本库依赖。若更换仓库或分支，需要同步修改这三处地址。这里的“本地化”指将模块依赖收纳到自己的仓库；Surge 安装后仍通过仓库的 Raw 地址获取脚本。

## 自动运行

每 10 分钟及网络切换时自动调用加白 API。面板保留 Surge 原生刷新按钮，按钮强制刷新；自动面板刷新可复用同配置、槽位和网络的 15 秒缓存。`update-interval=300` 表示打开面板时，若距上次更新已满 5 分钟就更新，并非额外的后台定时器。Panel 不发送通知，后台才发送首次状态、变化与恢复通知；相同失败最短间隔 30 分钟。

服务端仍为 `https://124.221.69.228/api/firewall/`，这是加白服务本身，须联网使用。模块保留它的 `DIRECT` 规则，以便服务端读取真实出口。最多并发两台机器；Panel 的总请求预算为 16 秒，后台为 45 秒，单次请求最多 6 / 10 秒，最多尝试 2 / 3 次。仅网络、408 和 5xx 错误重试，单机失败不影响其他结果。

同一运行实例合并并发刷新，多个实例通过会到期的存储租约尽力协调；客户端存储没有原子比较写入，不能保证跨实例完全消除重复。看到“刷新中”时可稍后查看。

## Panel

面板标题显示整体状态和成功机器数。正文把网络合并到出口行，单机把更新时间合并到白名单标题（精确到分钟），去掉组内空行；单机五条名单的正文从 10 行压到 7 行。多台机器之间仅保留一行空白，用“白名单 #1 / #2”区分，最后统一显示时间。Surge 根据内容和屏幕宽度决定实际高度，完整地址换行时会增加行数。

正文省去“机器 1 · 已加白”这类重复行头；名单保留完整 CIDR 和“本机”，固定槽位保留 `📌0`，蜂窝记录保留 `📶`。多个出口分别显示在对应名单下；失败时给出原因与处理提示。同一个历史成功时间只展示一次。

成功使用冰川蓝盾牌，部分成功或未启用使用琥珀色，失败或未生效使用红色。SF Symbols 图标和明确文案共同表达状态。Surge Panel 支持原生标题、纯文本、图标与图标色；字体、背景和外层布局由 Surge 管理。参见 [Surge Panel 官方文档](https://manual.nssurge.com/tools/panel.html)。

刷新失败显示原因和恢复方法。若同一配置、同一网络在 24 小时内有成功记录，会另列“上次成功名单”，历史名单不标“本机”；它不代表本次成功。未知容量显示 `?`，不假设上限为 5。参数错误明确显示在对应机器，不会默默改成自动槽位。历史按 Token 身份隔离，重排不会串号；同一出口切换到蜂窝也更新 `📶`，表示最近 24 小时观察到的蜂窝来源。

## 验证

在项目根目录运行 `npm test` 可验证公共核心和客户端实际入口，覆盖请求预算、缓存失效、通知冷却、参数异常、固定槽位 0、多机器隔离及 Token 脱敏。测试使用模拟响应，不调用真实加白 API。

此目录的 JS 是可独立运行的生成文件。维护时修改根目录 `src/firewall-core.js` 或 `src/surge.js`，执行 `npm run build` 后上传此目录；无需把 `src/` 上传为运行依赖。新版丢弃旧的无身份缓存，不复用按序号记录的历史，首次刷新会重新请求。

`output/surge-panel/` 存放开发用的文本排版预览，基于脚本真实返回值和明确的示例数据；它不需要上传。Windows 环境未运行 Surge，预览用于检查内容与换行，最终原生渲染和设备上的 API 连通性需在 Surge 中确认。
