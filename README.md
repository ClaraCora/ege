# ege

This repository mirrors the URLs listed in `kelee.lsr`, `png.lsr`, and `ad.lsr`.

The backup runs automatically every 12 hours and can also be started from the
Actions tab. Downloads use the following Loon request user agent:

```text
Loon/975 CFNetwork/3860.700.1 Darwin/25.6.0
```

Generated files are stored in `kelee/`, `png/`, and `ad/`. The raw GitHub URL
for each generated file can be used by Loon, Egern, or another compatible app.
